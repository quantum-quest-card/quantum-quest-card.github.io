# Quantum Quest — シングルプレイ試遊版

ブラウザで index.html を開く静的サイトです（HTTPで配信）。プレイヤー1人とCPU3勢力で遊べます。

- ログイン不要。ゲーム用APIへの接続は使用しません。
- 12ステップの説明つきチュートリアルを含みます。
- 通常ゲームの進行と振り返りメモは、遊んだブラウザの localStorage に保存します。
- GitHub Pages用にシングルプレイだけを有効にしています。
- 検索エンジンには noindex を指定していますが、アクセス制限ではありません。URLから誰でも閲覧できます。
- 画像とルールは2026年10月16日受領の入稿データと、その後の指定を反映しています。

既存の紹介ページと独立した /play/ ディレクトリで配信します。
